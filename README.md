# 📊 Análise Demográfica Brasileira, Mortalidade e Hábitos de Vida (Power BI)

## 📌 Sobre o Projeto

Este projeto consiste em um dashboard analítico desenvolvido no Microsoft Power BI com o objetivo de explorar dados demográficos, mortalidade e hábitos de vida da população brasileira por estados, municípios e regiões.

A solução integra dados públicos provenientes do IBGE e de bases relacionadas à atividade física e ao consumo de alimentos ultraprocessados, permitindo análises comparativas e correlações entre indicadores populacionais, hábitos de vida e mortalidade.

A versão atual do projeto ampliou significativamente as possibilidades de análise, incorporando novos indicadores, filtros avançados, visualizações interativas e um modelo de dados mais robusto.

# 🚀 Funcionalidades Implementadas

## 📍 Sidebar de Navegação

O dashboard foi reorganizado em módulos temáticos para facilitar a navegação e a análise dos dados:

* População
* Mortalidade
* Hábitos de Vida
* Personalize
* Glossário

Essa estrutura permite uma exploração mais intuitiva das informações e melhora a experiência do usuário.

---

## 🏠 Tela Inicial Interativa

A página inicial apresenta um gráfico interativo 2 em 1 que permite análises por:

* Estado
* Região

O recurso facilita comparações rápidas entre diferentes recortes geográficos, oferecendo uma visão geral dos principais indicadores do projeto.

---

## ❤️ Hábitos de Vida

Foi criada uma área específica para análise dos fatores comportamentais da população.

### Indicadores Disponíveis

* Taxa de Atividade Física
* Taxa de Consumo de Alimentos Ultraprocessados

### Funcionalidades

✔ Alternância dinâmica entre os indicadores através de botão interativo.

✔ Visualização comparativa entre estados e regiões.

✔ Gráfico de dispersão para análise da relação entre hábitos de vida e mortalidade.

Esse recurso possibilita identificar possíveis correlações entre fatores comportamentais e indicadores de saúde pública.

---

## 📈 Mortalidade

Foi implementado um indicador proporcional de taxa de mortalidade por estado, permitindo comparações mais equilibradas entre unidades federativas com populações distintas.

### Recursos Disponíveis

* Total de óbitos
* Taxa de mortalidade
* Comparação por estado
* Comparação por região
* Indicadores proporcionais

---

## 🎯 Personalize

### Filtros Disponíveis

### Indicadores Correlacionáveis

* Taxa de Atividade Física
* Consumo de Alimentos Ultraprocessados

Essa funcionalidade possibilita uma visão integrada dos dados, permitindo análises mais profundas e contextualizadas.

# 🎯 Objetivos do Projeto

* Analisar indicadores demográficos brasileiros.
* Avaliar a distribuição da mortalidade entre estados e regiões.
* Explorar possíveis relações entre hábitos de vida e mortalidade.
* Disponibilizar uma ferramenta interativa para análise de dados públicos.
* Facilitar a interpretação de informações estatísticas através de visualizações intuitivas.
* Apoiar estudos e pesquisas em saúde pública e demografia.

# 📌 Conclusão

A evolução do projeto transformou o dashboard em uma plataforma analítica mais completa, permitindo a integração entre dados demográficos, mortalidade e hábitos de vida.
